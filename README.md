# ML Practices: Image Classification, Ensemble Methods, and Bayesian Optimization

A three-notebook sequence covering the full lifecycle of building, tuning, and combining ML models for binary classification. Each notebook is self-contained but they are designed to flow together: Notebook 01 generates model predictions that Notebook 02 combines, and Notebook 03 shows a smarter alternative to the hyperparameter search used in Notebook 01.

## Learning Objectives

- Load and prepare image data for three different model architectures (LR, FCNN, CNN)
- Apply PCA as a feature extractor for classical models on pixel inputs
- Build fully connected and convolutional neural networks with Keras
- Use Random Search to tune hyperparameters across continuous and discrete ranges
- Understand why averaging diverse model predictions reduces error
- Quantify model diversity using prediction correlation
- Implement Forward Selection, Backward Elimination, and Random Ensemble Sampling
- Explain how Bayesian optimization uses a surrogate model to guide the search
- Use Optuna to run Bayesian hyperparameter optimization on a sklearn estimator
- Compare Grid Search, Random Search, and Bayesian optimization under equal evaluation budgets

## Step-by-Step Walkthrough

**Notebook 01 - Image Classification and Random Search**

Start here. The notebook uses `sklearn.datasets.load_digits()` - actual 8x8 pixel images of handwritten digits (0 vs 1) - so no external data download is needed.

Parts 1-3 build three architectures in increasing spatial sophistication: Logistic Regression treats every pixel independently, the FCNN learns non-linear combinations of all pixels, and the CNN applies learned filters that share weights across spatial positions. The architecture comparison is the core lesson: the CNN's inductive bias (spatial weight sharing) is the reason it generalizes better to images, especially larger ones.

Part 4 applies `RandomizedSearchCV` to all three model types and explains why log-uniform distributions are the right prior for scale hyperparameters. The notebook ends by saving 15 model predictions (5 per model type) to CSV - these are the input to Notebook 02.

**Notebook 02 - Ensemble Selection Methods**

Works with the prediction CSV files from Notebook 01, or generates equivalent predictions from sklearn's breast cancer dataset if those files are missing. Start by running the correlation analysis in Part 1 - it makes the ensemble selection results interpretable.

Parts 3, 4, and 5 implement the three selection strategies. The key insight is Part 2: when two models make uncorrelated errors, averaging their predictions reduces variance. The selection strategies are a search for the combination that maximizes diversity while maintaining individual quality.

**Notebook 03 - Bayesian Hyperparameter Optimization**

This notebook is independent - it uses breast cancer data and can be run without Notebooks 01 or 02. Parts 1 and 2 establish Grid Search and Random Search baselines; Part 2 also explains why random search with log-uniform priors is superior to grid search for scale hyperparameters.

Part 2 (theory) is conceptual - work through the GP surrogate and acquisition function explanation before running Part 3. The toy visualization in Part 2 makes the exploration-exploitation trade-off concrete before the Optuna code in Part 3 runs the full optimization.

## Key Concepts Glossary

| Term | Definition |
|------|------------|
| AUC | Area Under the ROC Curve - probability that a model ranks a random positive example above a random negative one; threshold-independent |
| Convolutional filter | A small learned weight matrix applied at every spatial position of an image; enables translation equivariance |
| Dropout | Regularization technique that randomly zeroes neuron outputs during training to prevent co-adaptation |
| Ensemble | A set of models whose predictions are combined (typically by averaging) to reduce variance |
| Forward Selection | Greedy algorithm that adds the best model at each step until a target ensemble size is reached |
| Gaussian Process | A probabilistic model over functions; used as a surrogate in Bayesian optimization to predict performance at untried settings |
| Acquisition function | A function that uses the surrogate's posterior to score candidate hyperparameter settings, balancing exploration vs. exploitation |
| Log-uniform distribution | A distribution uniform on the log scale; the right prior for hyperparameters that span orders of magnitude (learning rate, regularization) |
| PCA | Principal Component Analysis - finds orthogonal directions of maximum variance; used here to reduce pixel dimensionality before LR |
| Random Search | Hyperparameter tuning that samples configurations independently at random; more efficient than grid search when few hyperparameters dominate |
| Surrogate model | A cheap approximation of an expensive objective function; Bayesian optimization fits one to guide where to sample next |
| Translation equivariance | A CNN property: a filter that detects a feature at one location also detects it at any other location without relearning |
